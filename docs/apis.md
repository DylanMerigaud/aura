# APIs, frameworks and tools

Every external API, host, framework and tool used to build and ship AURA (both the 2D and the 3D build) and its Cloudflare Worker, one row each.

| Name | What it does here | Where |
|---|---|---|
| Gemini API, text (build time) | `gemini-3.8-flash` (fallback `gemini-3.5-flash-lite`), REST `generateContent` endpoint, structured JSON output (`responseMimeType: "application/json"`, a `responseJsonSchema`, `thinkingConfig.thinkingLevel: "low"`). Generates the 2D campaign's story, opponent, taunts, announcer lines and the QTE event script in one call, and the 3D build's fixed cast (story, opponent persona and color, taunts, announcer lines) per opponent, judged and regenerated by `scripts/eval-text.ts` on a failing gate. | `scripts/gen-campaign.ts`, `scripts/gen-cast.ts`, `scripts/eval-text.ts` |
| Gemini API, level 1 cast (build time) | `gemini-3.1-pro-preview`, structured JSON output. Wrote level 1 of `src/v2/cast.json`: THE TURNSTILE NINJA (@turnstile_ninja) at Chatelet, his persona, 8 taunts of 5 words, the announcer calls and two youth references; a line over its word budget is replaced by a hand written seed. | `scripts/gen-ninja.ts`, output `src/v2/cast.json` |
| Lyria and TTS regeneration (build time) | <MUSIC WINNERS PENDING> (lyria-3-pro-preview for level1, level2, the boss phase 2 and victory) and <VOICE WINNERS PENDING> (bake off per role: Gradium Voice Design, gemini-3.8-flash-tts, gemini-2.5-pro-preview-tts). Filled at the 17:30 integration from the winning manifests. | `assets/music/manifest.json`, `public/voice/v2/` |
| Gemini API, image (build time) | `gemini-3.1-flash-image` ("Nano Banana 2"), same REST endpoint with `responseModalities: ["IMAGE"]` and an `imageConfig.aspectRatio`. Generates the level backgrounds, opponent portraits and the title art. | `scripts/gen-art.ts` |
| Gemini API, live roast (via the Worker) | `gemini-3.8-flash`, the Interactions endpoint (`https://generativelanguage.googleapis.com/v1beta/interactions`), structured JSON output. Turns one run's stats into a short kind roast and a two word aura title for the results screen. Key stays in the Worker's own secret store, never in the browser. | `worker/src/roast.ts`, called from `src/v2/net/live.ts` (`fetchRoast`) |
| Lyria (build time, offline) | `lyria-3.5` (the five level tracks and the victory stinger) and `lyria-3-clip-preview` (the title loop and the boss's phase two clip). Model, requested and measured BPM, first beat, duration and per track analysis are catalogued in `assets/music/manifest.json`. | `assets/music/manifest.json`, tracks in `assets/music/*.mp3` |
| Gradium TTS API, offline render (build time) | REST endpoint `https://api.gradium.ai/api/post/speech/tts`, POST with an `x-api-key` header, `output_format: "opus"`. Renders every taunt and announcer line to audio for both the 2D campaign and the 3D cast. Distinct voices per opponent (Sterling, Reuben, Maeve, Freya, Garrett for the final boss) plus a shared announcer voice (Marcus). | `scripts/gen-voices.ts` (2D, `public/voice`), `scripts/gen-voices-v2.ts` (3D, `public/voice/v2`) |
| Gradium TTS API, live voice (via the Worker) | Same REST endpoint, `output_format: "wav"`, the response streamed straight back to the browser. Speaks the live announcer line on the results screen. Key stays in the Worker's own secret store. | `worker/src/voice.ts`, called from `src/v2/net/live.ts` (`speakLive`) |
| Cloudflare Workers | `worker/`, a small TypeScript Worker (no framework) deployed at https://aura-proxy.dylanmerigaud-pro.workers.dev. Fronts the two live calls above so the static build never ships a live API key; CORS locked to the game's own origins, 30 requests a minute per IP counted in a `RATE` KV namespace, any upstream failure falls back to the game's bundled lines. Deployed and developed with `wrangler`. | `worker/src/index.ts`, `worker/src/cors.ts`, `worker/src/ratelimit.ts`, `worker/wrangler.toml` |
| librosa (Python, build time) | Analyzes every Lyria track for beats, downbeats, onsets, per beat energy, drops and breakdowns, with a refined BPM pass beyond librosa's own quantized tempo estimate. Feeds the 3D campaign's beat grid and its deterministic chart generator. | `scripts/analyze-music.py`, output `src/v2/analysis.json` |
| three.js | The 3D build's whole render pipeline: the ring stage, the two Mixamo fighters and the instanced crowd, the camera director, the VFX (particles, shockwaves, the fullscreen composite pass) and a full resolution MSAA render target with bloom (`src/render3d/stage.ts`). Ships its own `RobotExpressive.glb` example asset (MIT) as the fallback rig. | `src/render3d/*`, `assets/3d/fallback/RobotExpressive.glb` |
| Web Audio API | The shared `AudioContext`, master bus with a limiter, a reusable noise buffer, procedural music and SFX (2D build), and the 3D build's layered mix (Lyria track bus with a lowpass riser and sidechain duck, crowd bed, one shot SFX and voice playback). The single clock every QTE timing decision is measured against, in both builds. | `src/audio/*` |
| Canvas 2D | The whole 2D build's rendering: the battle scene, characters, particles, HUD, camera transform, menus and screens. Kept as the fallback build, no WebGL. | `src/game/*`, `src/ui/draw.ts`, `src/main.ts` |
| Google Fonts | Anton, the 3D HUD's display type, loaded over `<link>` from `fonts.googleapis.com` and `fonts.gstatic.com`, SIL Open Font License. | `public/v2/index.html` |
| Pointer Events | Touch and mouse input on both builds, all timestamped onto the same `AudioContext` clock as keyboard input. 2D: swipes for HIT and COMBO, split tap zones for MASH, press and release for HOLD. 3D: edge taps and swipes for HIT, left or right half taps for MASH with a center release zone, press and hold anywhere for HOLD. | `src/qte/input.ts` (2D), `src/v2/ui/touch.ts`, `src/v2/ui/battleInput.ts` (3D) |
| localStorage | Calibrated input latency offset and campaign progress (unlocked levels, best score, combo, accuracy, burst and stars, cringe mode unlock in the 2D build), all wrapped in try or catch so a blocked or full store degrades to defaults instead of crashing. | `src/game/latency.ts`, `src/ui/progress.ts` (2D), `src/v2/ui/progress.ts`, the volume key in `src/v2/ui/settings.ts` (3D) |
| TypeScript | Project language throughout the game and the Worker, strict mode on, shared types for the campaign and QTE data so the game, the Gemini generators and the validator all agree on shape. | `src/`, `scripts/`, `worker/src/`, each package's own `tsconfig.json` |
| esbuild | Bundles `src/main.ts` (2D) and `src/v2/main.ts` (3D) into `public/game.js` and `public/v2/game.js` with sourcemaps and watch in dev, minified into `dist/` for GitHub Pages and itch.io. | `scripts/build.mjs` |
| vitest | Unit tests for the timing judge, the QTE runner, the campaign validator, the 3D chart generator and camera director, and the Worker's own routes. | `tests/*`, `worker/test/worker.test.ts` |
| tsx | Runs the TypeScript generation and tooling scripts directly (campaign, cast, art, voices, music analysis wiring, snapshots, balance sim, evals) with no separate compile step. | `package.json` scripts, `scripts/*` |
| @napi-rs/canvas | Native Canvas 2D implementation that lets the real 2D build's rendering code run headlessly in Node, standing in for the browser canvas in the snapshot and balance tools. | `scripts/snap.ts`, `scripts/snap-screens.ts`, `scripts/fake-env.ts`, `scripts/sim.ts` |
| ffmpeg | Transcodes Gradium's Ogg Opus output to mono 64 kbps mp3 for both voice pipelines, since Safari does not decode Opus reliably everywhere mp3 does. | `scripts/gen-voices.ts`, `scripts/gen-voices-v2.ts` |
| GitHub Pages | Hosts the public build, the latest (3D) at the root, the 2D build at `/v1/`, served from the `gh-pages` branch, no GitHub Actions involved. | `scripts/release/deploy-pages.sh`, https://dylanmerigaud.github.io/aura/, https://dylanmerigaud.github.io/aura/v1/ |
| itch.io | The submission build: the same staged bytes as Pages, zipped with `index.html` at the root. | `pnpm release:itch`, `scripts/release/build-itch.ts`, `aura-itch.zip` |
| pnpm | Package manager and script runner for the game and, as its own workspace, the Worker. | `package.json`, `worker/package.json` |
| wrangler | Cloudflare's CLI: local dev server with a local KV store, secret management, and deploy. | `worker/package.json` scripts, `worker/wrangler.toml` |

| @gltf-transform/core | Reads the Mixamo glb files headlessly (skeletons, animation channels, keyframe times) for the animation gate: beat windows, root drift, loop seams. | `scripts/eval-animation.ts`, `scripts/eval-lib.ts` |
| node-web-audio-api | A Web Audio implementation for Node, so the exact SFX recipes the game plays in the browser render offline to WAV previews and are measured in tests. | `scripts/render-sfx.ts`, `tests/sfx/*` |
| @types/node, @types/three | TypeScript type definitions for Node (the scripts) and three.js (the 3D renderer). Types only, nothing ships. | `tsconfig.json` |
| jsdom | A browser DOM for Node, so the live overlay, map, input and packs modules are tested against real elements and events in vitest. Tests only, nothing ships. | `tests/live/*`, `tests/map/*`, `tests/input/*`, `tests/packs/*` |
